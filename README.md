# Elagi-API-Testing-Project

Engineered and automated an API test suite for the Elagi healthcare e-commerce platform using Postman. Developed custom JavaScript pre-request and post-execution test scripts across 24 API endpoints to handle dynamic environment variables, token-based authorization, and response schema assertions. Validated essential business logic, including account creation with OTP verification, product filtering, dynamic cart updates, checkout processing, rare medicine requests, and performance SLAs (sub-1000ms response times).
